# Personal Study Tracker

A simple Python command-line application to record daily study sessions.

## Current Features

- Add a study session
- Store subject name, topic, study duration, and date
- View saved study sessions 
- View total study time for each subject
- Set a daily study goal and check today's progress
- View a report for the current week
- Export study sessions to CSV
